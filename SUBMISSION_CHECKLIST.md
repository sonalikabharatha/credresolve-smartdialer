# Submission checklist

- [ ] Run `npm install` successfully.
- [ ] Run `npm test` and review all test results.
- [ ] Run `npm start` and open the dashboard.
- [ ] Add sample agents and borrowers.
- [ ] Demonstrate progressive dialing.
- [ ] Demonstrate predictive pacing and show the safety decision.
- [ ] Simulate ANSWERED → CONNECTED → COMPLETED events.
- [ ] Demonstrate a duplicate event and an out-of-order event.
- [ ] Run `npm run simulate`.
- [ ] Run `npm run loadtest`.
- [ ] Read the README, architecture and decision documents until you can explain them.
- [ ] Remove local database files and `node_modules` before committing (already ignored by Git).
- [ ] Push the project to a public or recruiter-accessible GitHub repository.
- [ ] Verify the GitHub link in a private/incognito browser window.
